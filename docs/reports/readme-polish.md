### 3. 構造・冗長（観点 2・8）

- 段落内の複数文を一文一改行にした（箇条書き内は Markdown の都合で一行のまま）。

### 4. 語彙とフレーズ（観点 6・7、ng-vocab）

### 5. 記号・整形（観点 1）

- 日本語と半角英数字の間に半角スペースを入れた（全文）。例: 「MTGカード」→「MTG カード」、「Scryfallの」→「Scryfall の」、「約9.6MB」→「約 9.6 MB」、「510ms以上」→「510 ms 以上」、「`MVP_PORT`で」→「`MVP_PORT` で」。全角括弧や句読点に隣接する箇所は入れていない。

- 散文中の中黒の列挙を読点や「と」に置き換えた。例: 「モデル・辞書・カード画像自体」→「モデル、辞書、カード画像自体」、「日本語・英語版のみ」→「日本語版と英語版のみ」。

## 直さずに指摘する箇所（判断をお願いします）

意味が一意に決まらないか、直すと内容が変わる可能性があるため、変更していない。

1. **「画像・特徴量の外部送信やアカウント、アクセス解析は行いません（モデル配信元・カード検索語・為替ペアへの通信のみ発生します）」**
   - 「アカウント…は行いません」は述語がかみ合わない。「アカウント機能は提供しません」の意図と思われるが、確定できない。
   - 括弧内は、「モデル配信元」「カード検索語」「為替ペア」が、通信先なのか送信内容なのかが混在している。プライバシーに関する記述なので、正確な書き分けは作者の確認が必要。
2. **「日本語価格が欠けていても英語価格へ自動で置き換えることはありません」**
   - 「日本語価格」は、日本語版印刷の USD 価格とも、JPY 価格とも読める。
3. **用語の不統一**
   - 機能一覧は「JPY 概算」、注意点は「参考換算値」と表記が違う。同じものなら統一が望ましい。
4. **「CollectorVision、Cornelius、Milo モデル」**
   - 「モデル」が Milo だけにかかるのか、三者全体にかかるのか読み取れない。ライセンス記述のため変更していない。
5. **導入文の「MTG」**
   - 略語のまま初出になっている。Magic: The Gathering への言及は末尾のライセンス節にしかない。冒頭で補うのは追記になるため見送った。
6. **見出し「技術的な注意点・制限事項」「実モデル・実APIでの再現確認」**
   - 前者は二つの話題を含む可能性があり、後者は中黒と「実API」の半角スペースが規範と異なる。見出しは構造として変更対象外と指示されているため、そのままにした。
7. **認識が候補であることの重複**
   - 使い方節と注意点節で、ほぼ同じ文を繰り返している（観点 8）。節ごとの読者が異なるため残した。どちらかを削るか、参照にするかは判断をお願いします。
8. **太字**
   - 導入文と機能一覧の見出し語は、雰囲気の強調に近い（観点 6）。見た目の方針に関わるため、そのまま残した。

## 追加で確定させた 8 点

前節「直さずに指摘する箇所」の 8 点を、作者の方針に従って確定させ、README.md に反映した。

1. **外部送信・アカウント・アクセス解析の記述**
   - 述語がかみ合わない一文を、三文に分けた。
   - 「画像と特徴量は外部へ送信しません。」「アカウント機能とアクセス解析は提供していません。」「通信先は、モデル配信元、Scryfall、Frankfurter に限ります。Scryfall にはカード検索語を、Frankfurter には為替ペアを送ります。」とした。
   - 括弧内で通信先と送信内容が混在していたので、通信先の列挙と、送信内容の対応を分けた。
   - 元の記述（モデル配信元・カード検索語・為替ペアへの通信のみ）に含まれない通信先や送信内容は足していない。
2. **「日本語価格」**
   - 「日本語版の USD 価格」に変更した。「英語価格」も、対称性と誤読防止のため「英語版の USD 価格」にした。
3. **「JPY 概算」と「参考換算値」の統一**
   - 「JPY 概算」に統一した。機能一覧の「USD / JPY 概算」と注意点節が同じ語になった。
   - 注意点節の文は「JPY 概算に固定レートは使っていません」とした。
4. **「CollectorVision、Cornelius、Milo モデル」**
   - 「認識エンジン（CollectorVision）と認識モデル（Cornelius、Milo）」に変更した。
   - `public/recognition/THIRD-PARTY-NOTICES.md` で、CollectorVision はスキャナー本体（worker とカタログクライアント）、Cornelius 2.12 と Milo 1.0.0 はダウンロードされるモデルと記載されており、役割分担と矛盾しない。
5. **導入文の「MTG」**
   - 「MTG（Magic: The Gathering）」と、初出で正式名称を補った。
   - 末尾のライセンス節の「Magic: The Gathering と、そのカード名…」は、商標の帰属を述べる文なので変更せず、重複でも矛盾でもないと判断した。
6. **見出し**
   - 「実モデル・実APIでの再現確認」を「実モデルと実 API での再現確認」にした。中黒を除き、半角英数字の前後にスペースを入れた。`実モデル/プロバイダの再現試験` のような別表記は README.md に存在しなかった。
   - 「技術的な注意点・制限事項」は、技術的な注意点と制限事項の二つの話題を並べていた。内容も、認識の限界、表示方針、価格算出、レート制限、通信、表示設定が混在し、両者を分ける境界が明確でない。そのため分割せず、単一の「利用上の注意点」に改めた。
7. **「認識は候補です」の重複**
   - 使い方節の二文（「認識はあくまで候補です。」「実物の版、言語、加工（Foil など）は…」）を削除した。
   - 使い方の手順 4 は「残したいカードだけ「履歴に保存」します」で終えた。末尾の「保存は任意です」は、見出しの「任意保存」と機能一覧に同内容があるため外した。
   - 詳細は注意点節の「認識は候補です」に一本化した。
8. **太字**
   - 導入文の「日本語のカード名・ルールテキスト・参考価格」の太字を外した。誤読防止にも結論の明示にも当たらない。
   - 機能一覧の見出し語（「**カメラをかざすだけ**」等）は残した。箇条書きの各項目が何の機能かを読者が素早く把握するための見出しとして働いており、観点 6 が禁じる雰囲気作りの強調とは役割が違うと判断した。
   - 注意点節の「**認識は候補です**」、「**印刷本文**」「**Oracle 本文**」、ライセンス節の「**AGPL-3.0-or-later**」も太字のまま残している。今回の指示の対象外のため、判断していない。
