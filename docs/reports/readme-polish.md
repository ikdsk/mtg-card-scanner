## 直した箇所

### 1. 厳密さ（観点 3）

- 「実行前に**必ず** `npm run build` してください」を、「そのため、実行前に `npm run build` を実行してください」に変更した。絶対化の語を除き、直前の文（ビルド済みの静的ファイルを配信する）を理由として接続した。
- 注意点の「実物の版・言語・加工は**必ず**画面の表示と照合してください」から「必ず」を削除した。使い方節の同趣旨の文とそろえた。
- 「保存は**完全に**任意です」を「保存は任意です」に変更した（ng-vocab 8 強度の振り切り）。

### 2. 主体性（観点 5）

- 「確認操作なしで情報が表示されます」「カードが認識されると」を、「Mana Peek がカードを認識すると、確認操作なしで情報を表示します」に変更した。
- 「開いている間は表示が固定されます」を「表示を固定します」に変更した。
- 「ダウンロードされます」を「ダウンロードします」に変更した。
- 「カード名・参考価格・対応フォーマットがすぐ表示されます」を「カード名、参考価格、対応フォーマットを表示します」に変更した（「すぐ」も削除）。
- 「提携・公認された製品ではありません」を「提携しておらず、公認も受けていません」に変更した。
- 「尊重した間隔で」を「守る間隔で」に変更した（翻訳調の動詞）。
- 「カメラでかざす」を「カメラをかざす」に変更した（助詞の誤用）。

### 3. 構造・冗長（観点 2・8）

- 段落内の複数文を一文一改行にした（箇条書き内は Markdown の都合で一行のまま）。
- 体言止めや断片の文を文にした。例: 「価格は選択した印刷・加工のUSD欄から算出。」→「価格は、選択した印刷版と加工の USD 欄から算出します。」
- 長い一文を二文に分けた。ライセンス節の「…提供する義務があり、本リポジトリを公開することで…」を、義務の文と充足の文に分割した（内容は同じ）。
- 「他の印刷版の一覧」「選択した印刷版」と、「印刷」「印刷版」の表記をそろえた（観点 5 の術語統一）。
- 「画像認識→検索/価格/為替取得」の矢印を「画像認識から検索、価格、為替の取得まで」に変更し、コマンドの主語（「このコマンドは」）を補った。
- 行末が `：` だった「mock テストも用意しています：」を句点で終えた。

### 4. 語彙とフレーズ（観点 6・7、ng-vocab）

- ng-vocab の 8 カテゴリで点検した。1〜7 の NG 語はなかった。
- 該当したのはカテゴリ 8 の「完全に」「すぐ」のみ（上記の通り処理した）。
- 「すぐ確認できる」（導入文）と「すぐ確認できます」は、即時性が製品の価値（AGENTS.md の起動・スキャン遅延の方針）なので残した。

### 5. 記号・整形（観点 1）

- 日本語と半角英数字の間に半角スペースを入れた（全文）。例: 「MTGカード」→「MTG カード」、「Scryfallの」→「Scryfall の」、「約9.6MB」→「約 9.6 MB」、「510ms以上」→「510 ms 以上」、「`MVP_PORT`で」→「`MVP_PORT` で」。全角括弧や句読点に隣接する箇所は入れていない。
- ダッシュ「—」を全角コロン「：」に変更した（機能一覧の見出し語と説明の区切り）。
- 散文中の中黒の列挙を読点や「と」に置き換えた。例: 「モデル・辞書・カード画像自体」→「モデル、辞書、カード画像自体」、「日本語・英語版のみ」→「日本語版と英語版のみ」。
- alt テキストにも同じ整形を適用した。

## 直さずに指摘する箇所（判断をお願いします）

意味が一意に決まらないか、直すと内容が変わる可能性があるため、変更していない。

1. **「画像・特徴量の外部送信やアカウント、アクセス解析は行いません（モデル配信元・カード検索語・為替ペアへの通信のみ発生します）」**
   - 「アカウント…は行いません」は述語がかみ合わない。「アカウント機能は提供しません」の意図と思われるが、確定できない。
   - 括弧内は、「モデル配信元」「カード検索語」「為替ペア」が、通信先なのか送信内容なのかが混在している。プライバシーに関する記述なので、正確な書き分けは作者の確認が必要。
2. **「日本語価格が欠けていても英語価格へ自動で置き換えることはありません」**
   - 「日本語価格」は、日本語版印刷の USD 価格とも、JPY 価格とも読める。
3. **用語の不統一**
   - 機能一覧は「JPY 概算」、注意点は「参考換算値」と表記が違う。同じものなら統一が望ましい。
4. **「CollectorVision、Cornelius、Milo モデル」**
   - 「モデル」が Milo だけにかかるのか、三者全体にかかるのか読み取れない。ライセンス記述のため変更していない。
5. **導入文の「MTG」**
   - 略語のまま初出になっている。Magic: The Gathering への言及は末尾のライセンス節にしかない。冒頭で補うのは追記になるため見送った。
6. **見出し「技術的な注意点・制限事項」「実モデル・実APIでの再現確認」**
   - 前者は二つの話題を含む可能性があり、後者は中黒と「実API」の半角スペースが規範と異なる。見出しは構造として変更対象外と指示されているため、そのままにした。
7. **認識が候補であることの重複**
   - 使い方節と注意点節で、ほぼ同じ文を繰り返している（観点 8）。節ごとの読者が異なるため残した。どちらかを削るか、参照にするかは判断をお願いします。
8. **太字**
   - 導入文と機能一覧の見出し語は、雰囲気の強調に近い（観点 6）。見た目の方針に関わるため、そのまま残した。
